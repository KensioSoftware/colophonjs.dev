# colophonjs.dev docs website

https://colophonjs.dev/

Docs website for [Colophon](https://github.com/KensioSoftware/colophon), which
generates social meta images for the posts of a static website from their
frontmatter.

Built with [Astro](https://astro.build) and
[Starlight](https://starlight.astro.build), deployed to S3 and CloudFront with
AWS CDK.

## Where the content comes from

The pages are not written here. Each one is copied out of the colophon repo,
where `docs/<path>/README.md` is the source, and lands here as
`src/content/docs/<path>/index.md`.

```bash
pnpm scaffold-docs
```

That expects the colophon repo checked out beside this one. Set
`COLOPHON_REPO=/absolute/path/to/colophon` if it is somewhere else.

The script regenerates each page's frontmatter from its source and rewrites the
sidebar in `astro.config.mjs` between the marker comments. Adding a page to the
colophon repo means adding its route to a sidebar group in
`scripts/scaffold-docs.mts`, and the run fails until you do.

It also writes `public/llms.txt`, an annotated index of the docs in the
[llmstxt.org](https://llmstxt.org) convention, and `public/llms-full.txt`, every
page concatenated so a model needs one fetch rather than sixteen. Both are
generated, both are committed, and neither should be edited by hand.

Edit the pages in the colophon repo, then run the script. Editing the copies
here means losing the change on the next run.

## Social images

The site's own share images are generated by the package it documents. See
`colophon.config.ts`. `pnpm meta-img` writes the cards to `public/og/` and a
manifest to `src/data/colophon.json`, which `src/components/Head.astro` reads to
emit each page's meta tags. It runs automatically before a build.

The generated PNGs are not committed, since a build recreates them. The manifest
is, so that `pnpm dev` works on a fresh clone.

## Scripts

| Script               | What it does                                                      |
| -------------------- | ----------------------------------------------------------------- |
| `pnpm dev`           | Astro dev server.                                                 |
| `pnpm scaffold-docs` | Copy the docs from the colophon repo, then regenerate the images. |
| `pnpm meta-img`      | Regenerate the social images and the manifest.                    |
| `pnpm build`         | Build to `dist/`, regenerating the images first.                  |
| `pnpm preview`       | Serve the built site.                                             |
| `pnpm fmt`           | Prettier.                                                         |

## Deployment

```bash
pnpm build
pnpm exec cdk deploy
```

`scripts/local-dev.mts` deploys the synthesised template into a simulated AWS
with [Yulin](https://github.com/KensioSoftware/yulin) and prints a local URL, so
the CloudFront request rewriting can be checked without deploying.
